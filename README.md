# さくらクエスト

桜塚高校（大阪府立）への合格をめざす中学2年生のための、500日の学習プラン。診断・月ごとのマイルストーン・ごほうび・教科別ドリル・AI先生の設定まで、`index.html` 1枚に入っています。

## iPadで使う
1. `index.html` をiPadのSafariで開く（下の方法のどちらか）。
2. 共有ボタン →「ホーム画面に追加」で、アプリのように開けます。記録はそのiPadのブラウザに保存されます（「おうち」タブでバックアップできます）。

開く方法：
- GitHub Pages：このリポジトリの Settings → Pages で、ブランチと「/（root）」を選ぶと、URLが発行されます（無料プランでは公開リポジトリのみ）。
- Claudeのアーティファクトとして公開したリンク。

## AI先生
`index.html` の「AI先生」タブから、9人ぶんの設定をコピーできます。Claude Code では `.claude/agents/` に入っています。文章を直すときは `index.html` を直してから `node scripts/build-agents.mjs` を実行します。

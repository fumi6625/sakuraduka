# まなびクエスト（小5・6）作成仕様（エージェント共通）

`shogaku/` は、親アプリ（リポジトリ直下の さくらクエスト・中学生用）をコピーした**別アプリ**。親アプリ（直下の `src/` `scripts/` `tests/` `index.html` `CLAUDE.md`）は**絶対に変更しない**。作業は `shogaku/` の中だけ。

## 対象と時期
- 2026年10月に**小学5年**の子が、2028年3月（**小学6年の3月・卒業**）まで毎日使う。日付の流れ（2026-10〜2028-03）は親アプリと同じ。`S.exam='2028-03-01'` は「6年生のまとめの日」として使う。
- 出題は**小学5年・6年の学習内容だけ**（現行の学習指導要領・標準的な教科書の順。中学の内容は入れない。4年までの内容は「復習」として少しならよい）。
- 目標高校・入試・内申・偏差値・合格は**出さない**。目標は「5・6年の内容を身につけて、中学へ」。
- 子の前提は親アプリと同じ（集中が続かない・自分に甘い・叱らない・短い文）。小学生向けに、**漢字は5年までの配当漢字を中心に、むずかしい語にはふりがな（例：「人口密度（じんこうみつど）」）**。問題文は短く。
- 個人情報（本名・学校名・住所）は入れない。ごほうびで物を買わない。

## 教科
国語（国）・算数（内部コードは`数`、表示は「算数」）・英語（英。小学校の外国語）・理科（理）・社会（社）。

## データの書式（親アプリと同じ。例は `../src/data/` の同名ファイルを先頭だけ見る）
各ファイルは親アプリと同じ変数名（`let RAW_EW=`、`RAW_EW+=` など）・同じ書式。区切りは `|`。1行1問。`#タグ` の下に並べる。
- 4択（EG・JW・JG・MQ）：`問題文|正解|誤1|誤2|誤3|解説`
- 一問一答（SQ・OQ）：`問い|答え|ひとこと解説`（選択肢は同じタグの他の答えから自動で作る。**同じタグに、同じ型の答えが10個以上**あるようにする。答えは短い語に。答えの書き方は1つにそろえる＝別名をほかの問いの答えにしない）
- 英単語 EW：`英語|日本語|品詞`（品詞 n v adj adv prep conj pron aux int num）。`#1`〜`#4` が群。
- 不規則動詞 EV：`原形|過去形|過去分詞|意味`
- 並べかえ EO：`日本語|English[/別の正解]`（タグ `#小5` `#小6`）
- 英作文 EC・作文 JC・算数の考え方 MS：`問い|模範の答え|ひとこと解説`（自己採点）
- リスニング EL：`読み上げる英文|問い|正解|誤1|誤2|誤3|解説`
- 漢字の読み JK：`語|よみ|意味`。慣用句など JI：`語|意味`。類義語・対義語 JS：`語|対になる語`（タグ `#類義語` `#対義語`）
- 社会の年代ならべかえ OT：`古い順に < でつないだ出来事（3〜4個）|ひとこと`
- 長文 PASS_E（英語）・PASS_J（国語）：`{id:'e01',title:'…',text:\`本文\`,qs:[[問い,正解,誤1,誤2,誤3,解説],…]}`

### 選択肢の質（validate-data とテストが見張る）
- 誤答は、正解と**同じ種類・同じくらいの長さ**。正解をふくむ語・正解の別名・明らかに変なものは使わない。「どちら？」の2択は、4択にしない形で書く（できれば避ける）。
- 正解の位置はデータでは常に2番目（表示でシャッフルされる）。
- 同じ問題文の重複をしない。解説は1文で、なぜそうなるかを言う。

## タグ（ほかの係が、カリキュラムと難易度の表に使う。**この名前どおりに使う**）
- 英単語 EW の群：`#1`＝5年前半の基本語（あいさつ・数・色・曜日・月・食べ物・動物・教科・家族など）、`#2`＝5年後半、`#3`＝6年前半、`#4`＝6年後半（小学校で習う語の中で、ややむずかしい語）。中学で初めて習う語は入れない。
- 英文法 EG のタグ（表現の単元）：`あいさつ・自己紹介` `好きなもの` `できること` `誕生日・月日` `時間と日課` `行きたい所・したいこと` `道案内` `注文・ねだん` `人の紹介` `町・地域` `過去のできごと` `将来の夢` `思い出` `中学校でしたいこと`
- 並べかえ EO・リスニング EL・英作文 EC：タグ `#小5` `#小6`
- 漢字 JK・JW：タグ `#小5`（5年の配当漢字を使う語）`#小6`（6年の配当漢字を使う語）
- 慣用句など JI：`#慣用句` `#ことわざ` `#四字熟語` `#故事成語`。JS：`#類義語` `#対義語`
- 国語の文法 JG：`主語・述語` `修飾語` `言葉の種類` `敬語` `文の組み立て` `接続語` `指示語` `和語・漢語・外来語` `熟語の組み立て` `古文・漢文に親しむ` `俳句・短歌` `表現の工夫` `かなづかい・送りがな`
- 作文 JC：`#作文`
- 算数 MQ（単元。5年→6年の順）：5年 `整数と小数` `体積` `比例` `小数のかけ算` `小数のわり算` `合同な図形` `図形の角` `整数の性質` `分数と小数` `分数のたし算・ひき算` `平均` `単位量あたり` `速さ` `面積` `割合` `帯グラフと円グラフ` `正多角形と円` `角柱と円柱`／6年 `対称な図形` `文字と式` `分数のかけ算` `分数のわり算` `比` `拡大図と縮図` `円の面積` `角柱と円柱の体積` `比例と反比例` `場合の数` `データの調べ方`
- 算数の考え方 MS：`#文章題の線分図` `#図形の見方` `#きまりを見つける` `#説明のしかた`
- 理科 SQ：`分野/単元/答えの種類`（答えの種類は `用語` `実験` `しくみ` など）。分野/単元は次だけ：
  5年 `地学/天気` `生物/発芽と成長` `生物/メダカ` `生物/花と実` `生物/人のたんじょう` `地学/流れる水` `化学/とけ方` `物理/ふりこ` `物理/電磁石`／6年 `化学/燃焼` `生物/人の体` `生物/植物の養分と水` `生物/生物と環境` `地学/月と太陽` `地学/大地のつくり` `物理/てこ` `物理/電気の利用` `化学/水溶液`
- 社会 OQ：`分野/単元/答えの種類`。分野/単元は次だけ：
  5年 `地理/国土` `地理/気候` `地理/農業` `地理/水産業` `地理/工業` `地理/情報` `地理/環境と災害`／6年 `公民/憲法` `公民/政治` `歴史/古代`（縄文〜平安） `歴史/中世`（鎌倉〜室町） `歴史/近世`（安土桃山〜江戸） `歴史/近代`（明治〜昭和の戦争） `歴史/現代`（戦後〜今） `国際/世界と日本`
- 社会 OT：`#古代` `#中世` `#近世` `#近代` `#現代`

## 算数・理科の自動生成（GEN）の id（この名前で作る）
算数（`src/js/11-gen-math.js` と `12-gen-math2.js` を置きかえ）：
- 5年：`dec_mul`小数のかけ算 `dec_div`小数のわり算 `vol`直方体・立方体の体積 `angle`三角形・四角形・多角形の角 `multiple`倍数・約数（公倍数・公約数） `frac_add`分数のたし算・ひき算（通分・約分） `frac_dec`分数と小数・整数の関係 `avg`平均 `per_unit`単位量あたり（人口密度など） `speed`速さ・道のり・時間 `area`三角形・平行四辺形・台形・ひし形の面積 `percent`割合・百分率・歩合 `circle_len`円周
- 6年：`frac_mul`分数のかけ算 `frac_div`分数のわり算 `frac_mix`分数・小数のまじった計算 `letter_x`文字と式（xを求める） `ratio`比（比の値・等しい比・比の利用） `circle_area`円の面積 `prism_vol`角柱・円柱の体積 `prop_inv`比例と反比例 `comb`場合の数（並べ方・組み合わせ） `scale`拡大図・縮図・縮尺 `stat6`代表値（平均・中央値・最頻値）
理科（`src/js/13-gen-sci.js` を置きかえ。`subj:'理'`）：`pendulum`ふりこの周期（5年） `dissolve`ものがとける量（5年） `lever`てこのつりあい（6年）

## 担当ファイル（`shogaku/src/data/` 、`shogaku/src/js/`）
ファイルは丸ごと書きかえる（親アプリの中学の問題を1問も残さない）。ファイル名は同じ番号を使う（不要なファイルは削除してよい・新しい番号を足してよい）。

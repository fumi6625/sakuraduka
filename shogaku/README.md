# まなびクエスト（小学5・6年）

小学5年生（2026年10月時点）が、2028年3月の6年生の終わりまで毎日使う学習アプリ。5・6年の国語・算数・英語・理科・社会を、毎日3分から少しずつ。4年の内容は復習として混ぜる。目標高校や受験はなく、「5・6年の内容を身につけて、中学へ」が目標。

- 開く：`index.html`（1ファイルで動く。iPadのSafariで「ホーム画面に追加」）。
- 作る：`node scripts/build.mjs`（`src/` から `index.html` を作る）。
- 確かめる：`node scripts/validate-data.mjs && node --test tests/*.test.mjs`。
- 設計の説明は `CLAUDE.md`、教材の書式・タグは `SPEC.md`。
- 中学生用の親アプリ（リポジトリ直下）をもとにした別アプリ。記録はこのiPadのブラウザの中だけに保存されます（月1回、バックアップを）。
- 非公式の学習資料です。学校の教科書や先生の説明が、いちばん大事です。

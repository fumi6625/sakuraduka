# まなびクエスト（小学5・6年）

2026年10月に小学5年生の子が、2028年3月（6年生の3月）まで毎日使う、学習計画・教材・AI先生の一式。**目標高校・受験・内申・偏差値・合格はない**。目標は「5・6年の内容を身につけて、中学へ」。出題は5・6年が中心で、**4年の内容は「復習」**として少し混ぜる。作成の細かい決まり（タグ・書式・GENのid）は `SPEC.md`。

親アプリ（リポジトリ直下の さくらクエスト・中学生用）をコピーした別アプリ。**親の `src/` `scripts/` `tests/` `index.html` `CLAUDE.md` `.claude/` は変えない**。作業は `shogaku/` の中だけ。仕組み（毎日のルート・間隔反復・一本道・段階・テーマの色）は親と同じで、親の CLAUDE.md の設計の説明がそのまま当てはまる。

## ファイル
- `index.html` は**生成物（直さない）**。`node scripts/build.mjs` で `src/` から作る（1ファイル。iPadのSafari向け）。
- `src/head.html` / `style.css` / `body.html`：骨組み・見た目・静的ページ（5・6年の学びの旅・診断・教科ガイド・AI先生・おうちの人）。色は `style.css` の `--変数` だけで決め、5テーマ（ふつう・やさしい・ネオン・よる・くっきり）で値を入れかえる。
- `src/data/*.js`：教材・計画・AI先生。`00` 基本、`10` 月の目標（ROADMAP）、`15` 道のりの予定カーブ（`plan-curve.mjs` で作る）、`20` 教科ガイドと診断、`30` カリキュラム（CUR）、`40〜49` 英語、`50〜54` 国語、`55〜57` 算数、`60〜64` 理科、`65〜69` 社会、`90` AI先生。
- `src/js/*.js`：画面の動き。`11〜13` が算数・理科の自動生成（GEN）、`30-route.js` が毎日のルート、`34-level.js` が難易度の表示。
- `.claude/agents/*.md`：AI先生8人（`node scripts/build-agents.mjs` で `src/data/90-agents.js` から作る。直すのは90-agents.jsだけ）と、評価係 `ui-judge`・`flow-judge`。
- `scripts/`：`build` `build-agents` `validate-data` `simulate` `screens` `plan-curve` `headless`。`tests/`：`node --test tests/*.test.mjs`。

## 対象の子（設計の前提）
- ふだんあまり勉強せず、集中が続かない。だから「3分」から始め、量を段階的に増やす（ならし→ふつう→しっかり）／ホームは「いま やること」を1つ大きく／5問ごとにラウンドクリア／自己申告にたよらない／叱らない。
- 小学生向けに、問題文は短く、むずかしい漢字にはふりがな（例：人口密度（じんこうみつど））。個人情報は入れない。ごほうびで物を買わない（時間・権利・お金をかけない体験・ことば）。

## 表示のきまり
- 教科：国語・算数（コードの `'数'`）・英語・理科・社会。学年は「5年」「6年」。難易度は「小5・2学期レベル」「小6レベル」「小4レベル（4年の復習）」。チャレンジは計算Lv.3と算数の考え方（MS）だけ。
- 「合格ライン」→「クリアライン」（その日の最低ライン）。「合格への道のり」→「6年生のまとめへの道のり」（推定のめやす。確率は出さない・責めない・人とくらべない）。テストの記録は「学校のテスト（100点満点）」で、点数のめやすの線は出さない。`S.exam='2028-03-01'` は「6年生のまとめの日」。
- 長文：英語24題（40語以上）・国語30題（400字以上、800字以上が5題）。算数の自動生成は SPEC のとおり。

## 作業ルール
- 変更したら、コミットの前に `node scripts/build.mjs && node scripts/validate-data.mjs && node --test tests/*.test.mjs` を通す。教材やルートを変えたら `node scripts/plan-curve.mjs` で予定のカーブを作りなおす。ルートを変えたら `node scripts/simulate.mjs 500 0.9`（毎日）、`--dpw 3`、`--break 80:14` で確かめる。見た目を変えたら `node scripts/screens.mjs <フォルダ>` で撮る。
- 新しい教材を足したら、`src/js/34-level.js` の表に入れる。月ごとの教材は `src/data/30-curriculum.js`（CUR）。
- 通信（fetch等）は使わない。メールの自動送信は入れない。返答は日本語で短く。
- 子どもは学校支給のiPadで使う（Safariだけで動く・タップは44px以上）。

## 保護者の要望（2026-10-24）
- **見た目は親と別**：「ノートと はなまる」。方眼・ドット・ノート罫線の模様、飾りは はなまる（`splatSVG` の名前のまま形を変えた）と星。ななめのストライプ・飛沫・ななめラベルは使わない。親のピンク×紫×シアンの配色を使わない。5テーマの仕組みは親と同じ。
- **1日のマストは親の約1.5倍**：1日の見積りの上限は 15・30・45分（ならしは最初は短く、2週間で増える）。毎日の子で、漢字の読み・書きが500日でほぼ全部出ること、英単語の群4（6年後半）も卒業までに出ること（群3は2027-03-01、群4は2027-06-01に開く）。

# Google Apps Script で公開する手順（学校のiPadで github.io が開けないとき）

保護者のパソコン（またはスマホ）で、ご自身のGoogleアカウントで行う。期限はない。

1. https://script.google.com を開き、「新しいプロジェクト」を作る（名前：さくらクエスト）。
2. 左の「コード.gs（Code.gs）」の中身を、このフォルダの `Code.gs` に置きかえる。
3. 左の「ファイル」の＋ →「HTML」→ 名前を `index` にする（`.html` はつけない）。中身を全部消して、リポジトリの **`index.html` の全文**を貼る（GitHub の Raw 画面で全選択→コピー）。
4. 右上「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」。
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**（学校のアカウントでも開けるように）
5. 「デプロイ」→ 初回は権限の承認が出る（「詳細」→「安全ではないページに移動」→ 許可）。
6. 出てきた「ウェブアプリのURL」を、お子さんのiPadのSafariで開き、ブックマーク（共有→「ホーム画面に追加」）。

## 更新するとき
index.html を貼りなおし →「デプロイ」→「デプロイを管理」→ 鉛筆 → バージョン「新バージョン」→ デプロイ。URLは変わらない。

## 注意
- 記録（保存データ）は、ブラウザの制限で数日たつと消えることがある。月1回ではなく、**週1回は設定の「バックアップ」**をコピーしてメモに残す。
- URLが変わると記録は引き継がれない（バックアップから復元する）。
- 学校がGoogleのこのドメイン（script.google.com / googleusercontent.com）を止めていないことを、先に確認する。
